# Shade a Sphere 🌑

A daily drill for the anatomy of light on form. Two spheres per round,
each with a given sun: drag the terminator, core-shadow band, bounce
(reflected) light and occlusion shadow to where they belong, hit done,
and the true anatomy is revealed in lilac next to a flat-value plan —
learn from the delta. Sphere 1 is side-lit, sphere 2 goes high or back.

Scoring is placement-only with generous angular tolerances (terminator
weighs 0.4, core 0.25, occlusion 0.2, bounce 0.15; round = mean of the
two spheres). No rendering is judged — this is geometry, not mood.

Run it: `python3 -m http.server 8080` in this folder, open
`http://localhost:8080/`. Zero build, zero deps, no tracking.

Part of [Art Daily](https://artdaily.sadeali.com/) — tiny scored
warmups from [sadeali.com](https://sadeali.com/).
